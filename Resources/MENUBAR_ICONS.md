# Menubar icon (God Touch)

Drawn in code (`MenuBarIcon.swift`) — no PNG needed.

**Glyph:** CRT frame + two touch points + amber spark (`+`), like `LINK: [ON]` in the panel.

| State | Color |
|-------|-------|
| Connected | `#FFB000` + soft glow |
| Off | `#B87A00` dim |

Display size: **18×18 pt** in menu bar.
